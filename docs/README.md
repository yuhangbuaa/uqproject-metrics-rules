# 项目研究论文参考材料

本目录保存需求端、规划端和推理—检索方向的研究稿快照，供撰写两份项目研究报告时核对方法、实验设置和术语。当前报告 Markdown 主稿位于 `../deliverables/研究报告_20261025/`，同名 Word 文件是本次导入的原件；`../deliverables/研究报告_20261023/` 保留此前版本。论文叙述是研究材料，不能代替原始运行记录、代码配置或正式验收结果。

| 方向 | 本地材料 | 在项目中的用途 | 使用边界 |
| --- | --- | --- | --- |
| 需求端 PULSE | [LaTeX 工程](pulse-paper-reference/README.md) | 需求扰动、条件化不确定性、生成前识别与选择性澄清 | 六种文本扰动是实验构造操作，不直接等于项目级来源类别；实验数字按研究备份核对。 |
| 规划端 PlanCoder | [计划质量与代码生成研究稿](_AAAI27__PlanUncertainty_YUHANG_edit_-3.pdf) | 计划可行性、需求相关性、清晰度评分及分阶段修复 | 匿名稿件；论文报告值与本仓库已复算的记录分开说明，不据此推定录用或合同指标达成。此文件与外层工作区根目录的同名 PDF 内容一致。 |
| 推理—检索 BeyondUncertainty | [推理与检索不确定性研究稿](0VY5lY-1784_Beyond_Self_Knowledge_Pro.pdf) | 研究自报置信度如何传递为检索决策 | 实验对象是知识密集型问答，不能直接作为代码生成质量的验证。该匿名审稿稿件作为课题组内部参考材料保存在本仓库；稿件首页标有对外传播和引用限制，正式使用前须核实许可及稿件状态。 |

两份 PDF 均为复制到此处的稿件版本，文件名保留以便与原件核对。PlanCoder 的原始代码与实验记录、PULSE 的研究备份，以及 BeyondUncertainty 的原始实验材料，仍需分别核对。项目报告中的样本、模型、指标与结果应注明相应条件；论文稿件中的百分比或相关性不能自动当作项目测试结果。新导入的《智能软件决策多元不确定性主动感知方法》保留了 Word 原稿中的三份组内论文条目，是否删除待后续修订核定。
